# Jump Spikes 🚀

Un juego arcade 2D rápido y adictivo desarrollado en Unity. La premisa es simple: salta, esquiva los obstáculos y sobrevive el mayor tiempo posible para batir tu récord personal.

**Mecánicas Principales**
* **Generación Procedural:** Los obstáculos se generan dinámicamente de forma infinita, utilizando un sistema de *Object Pooling* para garantizar un rendimiento óptimo.
* **Control y Físicas:** Movimiento basado en impulsos rígidos con hitboxes ajustadas a medida (Pixel Perfect) para colisiones 100% justas.
* **Game Feel:** Animaciones de impacto, explosiones de partículas modulares al morir y pausas dramáticas (corrutinas) antes del Game Over.
* **Sistema de Puntuación:** Persistencia de datos para almacenar y actualizar automáticamente el "High Score" del jugador.

**Tecnologías y Arte**
* **Motor:** Unity (C#).
* **UI:** TextMeshPro con fuentes SDF generadas a medida para un escalado nítido en cualquier resolución.
* **Arte Visual:** Sprites y texturas de alta calidad por [Kenney](https://www.kenney.nl/), integrando patrones geométricos de fondo (Tiled Render).

**Cómo Jugar (Desarrolladores)**
1. Clona este repositorio: `git clone https://github.com/[tu-usuario]/[tu-repositorio].git`
2. Abre el proyecto a través de Unity Hub.
3. Ve a la carpeta `Scenes` y abre la escena principal.
4. Pulsa *Play* y haz clic/tap en la pantalla para saltar.
